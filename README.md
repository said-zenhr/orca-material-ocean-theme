# Material Theme Ocean for Orca

The Material Theme Ocean colour scheme for [Orca](https://www.onorca.dev): the app, the code editor and the terminal.

## Use it

1. Install it from **Settings → Plugins**.
2. In **Settings → Appearance**, select **Material Ocean** as the dark theme and the terminal theme.

## License

Apache-2.0, see [LICENSE](LICENSE). The colours come from the Material Theme Ocean VS Code theme. This port changes them to fit Orca: the code colours keep only the scopes Orca reads, and translucent colours that Orca refuses are mixed into the background.
